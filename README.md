# Online Courses Management System

## Project Description
Online Courses Management System is a web-based learning platform designed for IT and Computer Science students in Cambodia.  
The system provides structured video courses, free downloadable documents, and premium learning modules with Bakong KHQR payment integration.

This platform helps students access programming and technical learning materials anytime and anywhere through a modern online learning system.

---

## Features

### User Features
- User registration and login
- Browse IT and programming courses
- Watch online video lessons
- Read and download documents
- Access free learning modules
- Unlock premium modules using Bakong KHQR payment

### Admin Features
- Manage courses and modules
- Upload videos and documents
- Manage users
- Monitor payments
- Manage course categories
- Control access permissions

## System Workflow

1. User registers and logs into the system
2. User browses available IT and programming courses
3. Each course contains structured learning modules
4. First module is free for all users
5. Premium modules require payment
6. System generates Bakong KHQR payment QR code
7. User completes payment
8. System verifies payment and unlocks premium content
